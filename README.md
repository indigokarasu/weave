# weave

<p align="center">
  <img src="./assets/readme/hero.jpg" width="100%" alt="Weave: private social graph — provenance-backed contacts, relationships, preferences, and shared experiences">
</p>

Weave maintains a private social graph where every stored fact carries provenance — source type, reference, timestamp, and confidence score. It supports meeting prep, gift ideas, hosting context, city connections, and serendipity discovery. The embedded database initializes automatically.

**Capabilities:**
- Provenance-tagged contacts and relationships
- Meeting prep, gift ideas, hosting context
- Serendipity discovery through graph traversal
